## 整理包

运行 `python scripts/package_competition_submission.py --team-id 实际团队编号`。编号未知时省略参数，使用“待填团队编号”；这种版本不能直接作为完整终稿提交。生成位置为 `outputs/competition_delivery/`，已有同名包不会被覆盖。

包内分为“报名系统上传”和“百度网盘材料”，另有提交清单、部署说明、校验清单。所有网盘顶层文件使用“团队编号-AI+能源-智储云控-材料名称”。源码 ZIP 内保留项目原有相对路径，以确保导入、数据加载和验证脚本可运行；上传网盘的是整体 ZIP，无需将源码逐文件改名。

作品简称沿用仓库“智储云控”；报告封面的完整题名为“DOEF：让负荷预测服务于储能削峰决策”。报名系统作品名应核对并与最终提交命名保持一致；脚本支持 `--work-name` 修改文件名前缀，且不会改写报告正文。

源码包来自当前 Git 跟踪文件和本次整理脚本、说明；不包含 `.git`、本机原始大数据、缓存、临时文件或未跟踪的其他工作。历史阶段文件保留用于材料验证及复现依赖，当前成果以 `reports/submission/manifest.json` 为准。数据获取入口和许可署名见 `docs/DATASET.md`。原始数据不在 GitHub，按规则采用“获取方式”交付。

本次只整理已有成果，不重训模型、不改变科研结论。修复提交清单中未随 GUI 更新的 README 哈希，并重新运行材料检查。生成清单记录 Git 提交、文件来源、实际 SHA-256、字节数和本地差异；不会将本地整理包表述为已上传。
