# 智能云储动态视频演示 GUI

## 跨设备播放

便携版：将 `outputs/gui_demo/DOEF_Dynamic_Demo.html` 复制到另一台电脑，用浏览器打开。样式、动画和数据全部内嵌，无需 Python、网络或原项目文件。手机文件预览器未必执行 JavaScript，手机和平板建议使用局域网方式。

局域网：两台设备连接可互访的网络，在项目电脑上运行 `python gui/server.py --host 你的局域网IPv4地址 --port 8766`，其他设备打开 `http://该IPv4地址:8766`。用 ipconfig 查看地址；IP 改变后需重启并更换访问地址。项目电脑须保持程序运行。若其他设备无法连接，检查网络客户端隔离和防火墙端口规则；本任务没有修改防火墙或公开部署到互联网。

本机：`python gui/server.py`，打开 `http://127.0.0.1:8765`，仅需 Python 标准库。

## 演示操作

界面只保留「八建筑巡演 → 综合结果」这一条流程，没有其他页面入口或章节演示。

- 点击「开始巡演」：八栋建筑按固定顺序依次播放，每栋4秒（2.5秒绘制、1.5秒停留），约32秒后自动停在综合结果。
- 每栋曲线下方直接展示该建筑运行总览和电池配置；综合页展示八建筑明细、平均效果、算法公式及统一约束。
- 支持暂停、继续、下一栋、退出和重新巡演。空格开始或暂停/继续，右方向键跳到下一栋。
- 建议全屏录屏，综合页保留8–10秒供讲解。便携HTML具有相同功能，不自动录制视频。

## 数据来源

动态图使用 `outputs/phase8/test_daily_decision_metrics.csv`，DOEF对应 `DecisionSelectedPerBuilding`。每栋建筑、每种方法的30天记录在加载时与Phase 9最终整段峰值和平均后悔值核对；日期对齐、唯一性、连续性、有限数值、测试集标记及求解状态均检查，不一致拒绝加载。

横轴为调度日，纵轴为每日最大取电功率；各方法峰值可能出现在不同小时。当前为已有实验回放，不表示现场控制、实时重新求解或未保存的DOEF小时曲线。固定调度图片已不再用于GUI调度页。

数据入口集中于 `gui/server.py:SOURCES`。API `/api/demo` 返回记录和SHA-256来源清单。原算法、实验数据、科研图表、报告和提交材料未改动。便携HTML仅为展示副本，不替代科研源文件；其来源、实现版本、验收依据与文件哈希见 `outputs/gui_demo/manifest.json`。

## 重新生成与验证

```sh
python gui/export_demo.py
python -m unittest discover -s tests -p test_gui.py -v
node --check gui/app.js
node tests/test_gui_tour.cjs
```

修改GUI或源数据后先重新导出，再测试。已检查数据核对、来源哈希、破损输入拒绝、负向结果保留和便携同步；浏览器已检查回放推进、暂停、日期跳转和便携加载。其他实体设备上的访问仍取决于网络及目标浏览器。

巡演控制测试覆盖八建筑顺序、暂停后时钟不推进、恢复、跳转、最终汇总页和退出后不再自动切换。

每栋曲线下方直接展示同一建筑的完整运行总览（整个测试期前后峰值、削峰量、削峰率）及电池配置，无需切换页面。巡演最后综合页展示八建筑峰值与后悔值表、平均效果、算法公式和统一电池约束。

来源与便携版哈希统一按 LF 换行计算，避免 Windows、Linux 和 macOS 的换行差异导致误报。
